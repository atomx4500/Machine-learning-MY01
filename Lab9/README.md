In this lab, I built a classification model using the Random Forest algorithm on loan data from Lending Club. The aim was to predict whether a borrower would repay a loan in full based on financial features.

I began by exploring the dataset with methods such as info(), describe(), and head() to understand its structure. I then carried out exploratory data analysis by examining patterns between variables like FICO scores, loan purpose, and interest rates using histograms, count plots, and scatter plots.

After that, I prepared the data by choosing relevant features and splitting it into training and testing sets. I trained a Random Forest classifier and measured its performance with standard classification metrics.

In the final step, I reviewed the results to assess how well the model predicts loan repayment and how each feature affects the outcome. This lab showed that ensemble methods like Random Forest can improve classification accuracy compared to single models.
